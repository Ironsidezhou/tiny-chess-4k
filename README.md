A deterministic Python chess engine for the make.fun Tiny Chess challenge. It selects moves using alpha-beta search with a fixed node budget.

## Run it

Run with Python 3.13 and `MAKEFUN_ENV_URL` set to the competition environment:

```sh
python3.13 -P -s main.py
```
